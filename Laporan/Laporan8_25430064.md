## 1. Tujuan Praktikum
1. Memahami dan mengimplementasikan skrip instalasi bersih (*clean installation*) basis data relasional secara otomatis menggunakan MariaDB.
2. Melakukan otomatisasi pembuatan basis data, pemanggilan struktur DDL, dan pengisian data sampel DML melalui satu berkas skrip terpadu (`install_uts_064.sql`).
3. Melakukan verifikasi integritas tabel dan rekapitulasi jumlah baris data pada basis data `toko_064`.

## 2. Ringkasan Dasar Teori
* **Clean Installation (Instalasi Bersih):** Proses menghapus basis data yang lama (jika ada) dan membangun kembali struktur serta datanya dari awal secara bersih untuk menghindari inkonsistensi data.
* **Perintah `SOURCE`:** Perintah pada MariaDB/MySQL untuk membaca dan mengeksekusi sekumpulan kueri SQL dari file eksternal dengan menggunakan direktori absolut (*absolute path*) agar terhindar dari galat berkas tidak ditemukan (*Error file not found*).
* **INFORMATION_SCHEMA:** Basis data internal pada sistem MariaDB yang menyimpan metadata mengenai seluruh basis data, tabel, kolom, dan hak akses yang aktif.
