2. Ringkasan Dasar Teori

Basis data adalah kumpulan data terorganisasi yang dikelola oleh Sistem Manajemen Basis Data (DBMS) seperti MariaDB. MariaDB menggunakan arsitektur klien-server di mana proses server (mysqld) mendengarkan pada port TCP 3306, sementara klien seperti CLI mysql atau phpMyAdmin mengirimkan perintah SQL.
Buku ini menerapkan prinsip hak akses minimum (least privilege): akun root hanya digunakan untuk administrasi, sedangkan pekerjaan harian menggunakan akun kerja yang terbatas pada satu basis data. Selain itu, Git digunakan untuk mencatat riwayat perubahan berkas (commit) secara bertahap sebagai bukti proses pengerjaan praktikum.

4. Jawaban Titik Analisis

Titik Analisis 1: Tombol pada XAMPP Control Panel tertulis "MySQL", padahal paket yang dijalankan adalah MariaDB 10.4.32. Konsekuensinya, dokumentasi MySQL masih relevan untuk sintaks SQL standar, namun untuk fitur spesifik mesin penyimpanan, tata kelola akun, atau pesan galat yang spesifik, kita harus merujuk langsung ke dokumentasi resmi MariaDB.
Titik Analisis 2: Ketika mencoba masuk tanpa opsi -p setelah root diberi password, server menolak dengan pesan galat ERROR 1045 ... (using password: NO). Bagian using password: NO mengonfirmasi bahwa klien sama sekali tidak mengirimkan password ke server.
Titik Analisis 3: information_schema vs mysql (Galat 1044): Akun mhs_064 tetap dapat melihat information_schema karena basis data tersebut adalah metadata sistem yang bersifat publik untuk pembacaan skema dasar. Sebaliknya, akses ke basis data mysql ditolak dengan ERROR 1044 karena akun tersebut tidak memiliki hak istimewa (privileges) di luar basis data praktikum miliknya sendiri.
Titik Analisis 4: Mode cookie pada phpMyAdmin jauh lebih aman daripada mode config karena mode config menyimpan password teks mentah di dalam berkas konfigurasi server, sehingga siapa pun yang bisa membaca file tersebut akan langsung mengetahui password administrator. Mode cookie mewajibkan pengguna mengetik kredensial setiap kali sesi masuk dimulai.
